# Review-ejercicios-de-clase

## Descripción

Este repositorio contiene la recopilación y práctica de los temas trabajados durante el **Skill de MySQL II (Bases de Datos)**.

El objetivo principal del repositorio es aplicar de manera práctica los conceptos vistos en clase, utilizando **MySQL** para diseñar, consultar, modificar y administrar bases de datos siguiendo buenas prácticas de organización y estructuración.

Como parte de los ejercicios desarrollados, se trabajó con una **base de datos relacionada con un gimnasio**, cuyo modelo fue llevado hasta la **Cuarta Forma Normal (4FN)** con el propósito de aplicar los conceptos de normalización y reducir problemas relacionados con redundancia, dependencias y duplicidad de información.

Además del diseño y normalización de la base de datos, en este repositorio se encuentran ejercicios orientados a reforzar los diferentes temas abordados durante el curso.

## Temas trabajados

Durante el desarrollo de las actividades se trabajaron los siguientes temas:

* **Consultas avanzadas**

  * Consultas para obtener y analizar información de la base de datos.
  * Uso de diferentes estructuras y condiciones para realizar consultas más complejas.

* **Procedimientos almacenados**

  * Creación de procedimientos para encapsular operaciones y consultas dentro de la base de datos.
  * Ejecución de procesos mediante parámetros.

* **Funciones**

  * Creación y utilización de funciones almacenadas.
  * Automatización de operaciones que pueden ser reutilizadas dentro de diferentes consultas.

* **Transacciones**

  * Manejo de operaciones que deben ejecutarse de manera controlada.
  * Aplicación de `COMMIT` y `ROLLBACK` para garantizar la integridad de los datos.

* **Seguridad y permisos**

  * Gestión de usuarios y permisos dentro de MySQL.
  * Control del acceso a los diferentes recursos de la base de datos.

* **Eventos y Triggers**

  * Creación de eventos programados para ejecutar tareas automáticamente.
  * Implementación de triggers para ejecutar acciones de forma automática cuando ocurren determinados eventos sobre las tablas.

## Base de datos del gimnasio

Uno de los ejercicios principales desarrollados durante las clases consistió en el diseño de una base de datos para administrar la información de un **gimnasio**.

El modelo fue analizado y estructurado aplicando técnicas de **normalización**, llegando hasta la **Cuarta Forma Normal (4FN)**.

El proceso de normalización permitió organizar la información en diferentes tablas relacionadas, evitando almacenar datos innecesariamente repetidos y separando correctamente las relaciones que podían generar dependencias multivaluadas.

De esta manera, la base de datos representa de forma más organizada la información propia de un gimnasio y permite realizar operaciones sobre los datos manteniendo una estructura consistente.

## Propósito del repositorio

Este repositorio funciona como una evidencia del trabajo realizado durante el **Skill de MySQL II**, permitiendo revisar los conceptos aprendidos y las soluciones desarrolladas durante las clases.
